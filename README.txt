HOW TO PUBLISH USING GITHUB PAGES
1. Sign in at https://github.com/
2. Create a new Public repository named:
   mdm-register-website
3. Upload index.html, privacy.html, and README.txt to the repository root.
4. Open the repository's Settings.
5. Select Pages.
6. Under Build and deployment, choose "Deploy from a branch".
7. Select branch "main" and folder "/ (root)", then save.
8. Wait for GitHub Pages to publish the site. The site URL will appear on the Pages settings screen.
9. Open the homepage URL and check that it loads.
10. Open the privacy page by adding "privacy.html" to the end of the website URL.

IMPORTANT PRIVACY POLICY CHECKS BEFORE PUBLISHING
- Review the Privacy Policy against the actual MDM Register app code.
- Confirm exactly which records and settings are included in Google Drive backups.
- Confirm which Google Drive permissions (OAuth scopes) the app requests.
- Check whether any third-party libraries or SDKs transmit data.
- Replace the effective date if you revise the policy.
- Keep the contact email correct.
- Do not publish claims that have not been verified against the app.

GOOGLE OAUTH NOTE
Publishing these pages does not automatically approve Google OAuth verification. Google may require a verified domain and additional review depending on the app and the permissions requested.
